app running on Linux because I want to stay in my own setup.

### Current experiment: Native Instruments on Linux

Working through a Wine setup for Maschine and Native Access, with the aim of
turning the findings into a streamlined setup others can reproduce.

- **Confirmed so far:** Maschine launches and activates; Native Access login and library access work.
- **Still testing:** audio playback, controller support, plugin compatibility, and installation from scratch.

This is an experiment in progress. I'll share the scripts and verified steps
when they're ready—not account data or proprietary application files.
